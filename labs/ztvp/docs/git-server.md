# Local git server

The git server has been installed in a different VM for an easier monitoring and control.  
It provides SSH push/pull access with `git-shell` and a read-only web UI with `cgit` behind `nginx`.

## VM settings

* vCPUs: 2
* Memory: 4096 MB
* Disk: 25 GB
* OS: Fedora Linux 44
* Hostname: `git-server.pinnedis.local.lab`
* Network: `pinnedis-network` (`192.168.129.0/24`)
* MAC: `52:54:00:9c:93:37`
* IP: `192.168.129.201`

## Create the VM

Download the Fedora Server guest image:

```shell
wget https://download.fedoraproject.org/pub/fedora/linux/releases/44/Server/x86_64/images/Fedora-Server-Guest-Generic-44-1.7.x86_64.qcow2 \
  -O /home/libvirt-ocp/git-server.qcow2
```

Resize the disk:

```shell
qemu-img resize /home/libvirt-ocp/git-server.qcow2 25G
```

Import the image and create the domain.  
`cloud-init` generates a temporary root password on first boot and then disables itself.

```shell
virt-install \
  --name git-server \
  --memory 4096 \
  --vcpus 2 \
  --cpu host \
  --import \
  --disk path=/home/libvirt-ocp/git-server.qcow2,format=qcow2,bus=virtio \
  --os-variant fedora40 \
  --network network=pinnedis-net,mac=52:54:00:9c:93:37,model=virtio \
  --graphics none \
  --console pty,target_type=serial \
  --cloud-init root-password-generate=on,disable=on
```

Enable autostart:

```shell
virsh autostart git-server
```

Name resolution for `git-server` is provided by `dnsmasq` on the beaker host, using the static DHCP entry in `inventory/host_vars/beaker.yaml`.

## Software setup

### Packages

```shell
dnf install git nginx cgit fcgiwrap -y
```

### git and git-shell

Create a dedicated `git` user restricted to Git operations over SSH:

```shell
grep -q '^/usr/bin/git-shell$' /etc/shells || echo '/usr/bin/git-shell' >> /etc/shells
useradd --system --create-home --home-dir /home/git --shell /usr/bin/git-shell git
mkdir -p /home/git/.ssh
chmod 700 /home/git/.ssh
touch /home/git/.ssh/authorized_keys
chmod 600 /home/git/.ssh/authorized_keys
chown -R git:git /home/git
```

Append client public keys to `/home/git/.ssh/authorized_keys`.  
Optionally harden each key:

```
no-port-forwarding,no-X11-forwarding,no-agent-forwarding,no-pty ssh-ed25519 AAAA... comment
```

Create a bare repository:

```shell
sudo -u git git init --bare /home/git/example.git
echo "Example repository" > /home/git/example.git/description
```

Clients can push and pull with:

```shell
git remote add origin git@git-server.pinnedis.local.lab:example.git
git push -u origin main
```

### nginx

Create self-signed certificates:

```
mkdir /etc/pki/nginx/
openssl req -newkey rsa:4096 -nodes -sha256 -keyout /etc/pki/nginx/git.key \
  -subj "/C=US/ST=North Carolina/L=Raleigh/O=Red Hat/CN=git-server.pinnedis.local.lab" \
  -addext "subjectAltName=DNS:git-server.pinnedis.local.lab" \
  -x509 -days 730 -out /etc/pki/nginx/git.pem
```

Add reverse proxy / cgit configuration:

```
    server {
        listen       443 ssl;
        listen       [::]:443 ssl;
        http2        on;
        server_name  git-server.pinnedis.local.lab;

        access_log /var/log/nginx/git-access.log;
        error_log /var/log/nginx/git-error.log;

        ssl_certificate "/etc/pki/nginx/git.pem";
        ssl_certificate_key "/etc/pki/nginx/git.key";
        ssl_session_cache shared:SSL:1m;
        ssl_session_timeout  10m;
        ssl_ciphers PROFILE=SYSTEM;
        ssl_prefer_server_ciphers on;

        root /usr/share/cgit;
        try_files $uri @cgit;

        location @cgit {
            include fastcgi_params;
            fastcgi_param SCRIPT_FILENAME /var/www/cgi-bin/cgit;
            fastcgi_param PATH_INFO       $uri;
            fastcgi_param QUERY_STRING    $args;
            fastcgi_param HTTP_HOST       $server_name;
            fastcgi_pass unix:/run/fcgiwrap/fcgiwrap-nginx.sock;
        }
    }
```

Enable `fcgiwrap` for the `nginx` user and start `nginx`:

```shell
systemctl enable fcgiwrap@nginx.socket --now
systemctl enable nginx.service --now
```

Enable the service in `firewalld`:

```shell
firewall-cmd --zone FedoraServer --add-service=https --permanent
firewall-cmd --zone FedoraServer --add-service=ssh --permanent
firewall-cmd --reload
```

Allow `nginx` / `fcgiwrap` to read the repositories.  
> NOTE: the `ausearch` will work after the first attempt to browse cgit. It uses the data generated by the AVC.

```shell
ausearch -c 'nginx' --raw | audit2allow -M my-nginx
semodule -X 300 -i my-nginx.pp
```

Also allow CGI execution if needed:

```shell
setsebool -P httpd_enable_cgi 1
```

### cgit

Edit `/etc/cgitrc`:

```
css=/cgit.css
logo=/cgit.png
favicon=/favicon.ico
virtual-root=/
cache-size=200
enable-http-clone=1
scan-path=/home/git
```

Ensure the `nginx` group can read the repositories and that new objects inherit group ownership:

```shell
usermod -aG git nginx
chgrp -R git /home/git
chmod -R g+rX /home/git
find /home/git -type d -exec chmod g+s {} \;
```

Restart services after the configuration changes:

```shell
systemctl restart fcgiwrap@nginx.socket nginx.service
```

## Validate

From an external host, clone over SSH:

```shell
git clone git@git-server.pinnedis.local.lab:example.git
```

Browse the repository UI:

```shell
curl -k https://git-server.pinnedis.local.lab/
```

Push a change and confirm it appears in cgit:

```shell
cd example
echo "hello" > README.md
git add README.md && git commit -m "Add README" && git push
curl -k https://git-server.pinnedis.local.lab/example/
```
